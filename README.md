## Tecnología

| Tecnología | Uso                                       |
| ----------- | ----------------------------------------- |
| HTML5       | Estructura semántica y accesible         |
| CSS3        | Estilos personalizados con Grid y Flexbox |
| Bootstrap   | Layout responsive y componentes de UI     |
| JavaScript  | Theme toggle, scroll reveal, animaciones  |

---

## Funcionalidades

* Modo oscuro por defecto con toggle persistente (`localStorage`)
* Animaciones de entrada al hacer scroll (`IntersectionObserver`)
* Enlace de navegación activo sincronizado con el scroll
* Barras de progreso animadas al entrar en el viewport
* Sombra dinámica del navbar al desplazarse
* Sección de certificados con descarga de PDFs
