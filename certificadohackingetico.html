¿Qué aprendí?

Pensar como atacante
para defender mejor

Este certificado acredita mi asistencia a las jornadas del Curso de Hacking Ético: de 0 a Hackear Aplicaciones, impartido por BIG school con una duración de 6 horas. Di mis primeros pasos en ciberseguridad y comprendí cómo se analizan y vulneran las aplicaciones de forma ética y controlada.

  • Fundamentos de hacking ético y ciberseguridad
  • Mentalidad de atacante para detectar vulnerabilidades
  • Análisis de la seguridad de aplicaciones
  • Vulnerabilidades web más comunes
  • Prácticas éticas y legales en pruebas de seguridad
  • Buenas prácticas para desarrollar software más seguro

Este curso me dio una nueva perspectiva como desarrollador: entender cómo se ataca una aplicación es el primer paso para construirlas seguras desde el diseño.
